# Dashboard_Xbox
Dashboard para verificar as vendas da Microsoft na plataforma Xbox

Foi criado várias abas e cada uma delas tem uma função:

Na aba assets se encontra os recursos (Imagens e paletas de cores) que vamos usar no dashboard.

Temos a aba base que é onde se encontra toda a nossa base de informações que vamos utilizar.

Na aba cálculos vamos fazer nossas perguntas de negócios e criar uma tabela dinâmica daquilo que queremos e podemos usar a mesma tabela dinâmica e criar apartir dela um gráfico dinâmico.

Na mesma aba vamos em uma coluna e célula separada ao lado e escrevemos "=" e selecionamos o total de cada tabela dinâmica pois mais tarde vamos usar essa célula para fazer um Big Number.

E por fim a aba dashboard, nela vamos reunir todas as informações das perguntas de negócios e organizar de uma maneira que fique fácil de entender as informações contidas lá, pra isso devemos deixar numa paletas de cores parecidas para que não aja poluição visual, organizar a posição das imagens, gráficos e dados que pegamos da aba cálculos.
